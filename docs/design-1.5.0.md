# Web 1.5.0 — 3問から、すぐ振り返る

2026-10-23。作者が利用者としてv1.1の短い操作を支持したことを受けた改修。Web 1.5.0-dialogue-rc.1 / Dialogue 1.1-prototype / Quick instrument 1.0。

- 3問を1ページで回答し、1回の操作で3領域の原回答を表示。入力例も直接結果へ進む。
- 結果の上部に回答修正を置き、3領域と任意の会話欄が見渡しやすい余白へ調整。スマートフォンでは結果カードを短い縦並びで表示。
- 背景確認・記録方法選択・計画の専用画面と必須通過を廃止。結果画面の任意展開から会話とメモを利用。
- 未選択は未記録と表示。notesモードを本人と明示選択したときだけメモを入力可能。
- 背景メモを修正しても既存の計画を消さず、確認待ちを画面・コピー・印刷に表示。「本人と確認した」で解除。確認待ちは保存を妨げない。
- 回答変更・記録方法変更は予告のうえ以前の背景と計画を消す。
- 質問原文、想起期間、回答区分、Quick v1.0採点を維持。不完全回答を0点補完しない。参考点は折りたたみ、閾値・自動優先順位なし。
- 記録の自動送信・自動保存なし。採点と対話版を区別し、過去研究の評価対象版と混同しない。

完答の場合の最短操作はホームから開始1回、回答3回、振り返り1回の計5回（スクロール等は別）。これは操作数の記述であり、所要時間や使いやすさの比較実証ではない。PCは3問を横並び、狭い画面は縦並び。実際の使用者による比較評価は未実施。

技術検証と公開確認の記録は別途保存。表示確認・単体テストの成功を実装効果や臨床的妥当性の証明としない。

記録画面にない任意の話題欄は、値がある場合だけコピー・印刷へ出力。既存の状態項目や記録内容は維持する。

背景・計画を記録しない場合、印刷では重複していた未記録欄を1節にまとめる。原回答、想起期間、参考点、版番号、引用は残す。
