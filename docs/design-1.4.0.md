# Web 1.4.0 — 一つずつ答え、対話を進める画面

2026-10-23。Web 1.4.0-dialogue-rc.1 の操作と画面表示を整理する。Quick v1.0 と Dialogue v1.0-prototype は変更しない。

## 操作の流れ

- 質問は1問ずつ表示し、原設問・選択肢・想起期間を保つ。選択だけで画面を切り替えず、明示的な「次へ」で進む。未回答や不明の扱いも維持する。
- 背景確認は「話すだけ」「メモを残す」を本人と選ぶ。初期選択は設けない。座位の場面を主質問にし、その他の生活背景は必要なときに展開する。
- 次の一歩は本人の3方針を維持し、行動入力を中心にする。いつ・支援・振り返り日は任意で展開する。話題を選び直すことで入力内容が消える操作を避けるため、計画の話題選択は画面に置かない。状態管理や過去の話題データの扱いは変えない。
- 生のメモ入力の前に、個人情報を入れないこと、自動送信・自動保存しないこと、再読み込みで消えること、本人と記録範囲を確認することを明示する。元のプライバシー・同意説明も展開して読める。
- まとめ画面は原回答と記入済みの内容を主表示にし、未記入の補足行は省略する。メモが空なら「未記入」と示す。印刷には従来の全項目、原質問、想起期間、注意を残す。画面用の短い表示と印刷用の全文が重複しないよう切り替える。

## 見た目と画像

白を基調に青とライム色を組み合わせ、余白と大きな操作ボタンで進行を分かりやすくする。高齢者や介護場面の人物表現は使わず、特定の年齢層を対象とする印象を避ける。

ホームには ImageGen で生成した自然と小道の画像を装飾として置く。測定結果・推奨行動・健康効果を示す画像ではない。装飾画像は空の代替テキストとし、読み上げや印刷の対象から外す。写真に写った実在の参加者・利用者を示すものではない。

## 変更しない仕様と検証の限界

採点、設問、選択肢、想起期間、原回答、科学的説明、未回答の扱いを維持する。得点は参考値であり、臨床閾値や新しい精密尺度を追加しない。Web・Quick採点・Dialogueの版は区別する。アプリ改良が原著論文の数値を遡って修正することはない。

技術的な動作・表示・印刷の確認と、実利用者による使いやすさの検証は別である。実利用者のユーザビリティ検証は未実施で、対話支援の有用性や臨床効果を示すものではない。健康教室等でのデータ収集には、研究計画・同意・倫理承認範囲の確認が必要となる。
